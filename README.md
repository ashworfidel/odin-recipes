# odin-recipes

The Odin Recipes project is the first project given to Odinites to evaluate the concepts and understanding they have gained from various topics they have covered, such as Git for version control, HTML, the Command Line Interface, Shell, and GitHub.
By doing this project, I have gained many skills to become a better web developer in the future.

Skills I have gained:

1. HTML boilerplate: Understanding the basic structure that makes up a web page.
2. HTML fundamentals: I learned the basics of HTML tags, elements, content, and attributes.
3. Web development concepts: I was exposed to a lot of new information that is highly important for any web developer to know.
4. Developer tools: I gained skills in setting up a Git environment to run my own projects. I also had the privilege of learning the basics of the Command Line Interface, Shell, and many other things I previously had no idea about.
I am so happy to join other Odinites who are working on this project.
